# DevShire

**Write live. Your audience watches every keystroke.**

DevShire is live code and text sharing in real time. Start a session, share one link, and
everyone sees your code or text appear as you type. No account, no install, free.

**→ [devshire.in](https://devshire.in)**

## Made for

- **Teaching:** walk a class through code line by line.
- **Coding interviews:** watch a candidate think, then hand them the pen.
- **Pair writing:** draft together, one writer at a time.
- **Live Q&A:** answer questions while you write.

## Features

- **Live typing:** viewers see every change as it happens.
- **Code mode:** syntax colours, line numbers and auto-indent for JavaScript,
  TypeScript, Python, Go, Rust, Java, C, C++, C#, SQL, Shell and JSON.
- **Rich text:** fonts, sizes, bold, italic, underline, colours and highlights.
- **Pass the pen:** viewers request to write; the host approves, denies or takes it back.
- **Audience interaction:** reactions, raised hands and questions, kept out of the document.
- **Watching list:** see who is in the session.
- **Replay:** watch how the text was written, with a timeline and speed control.
- **Download:** Word, PDF, or a source file (`.py`, `.go`, …) for code.
- **Light and dark mode.**
- **Reliable:** sessions survive server restarts, and everyone reconnects automatically.

## Privacy and security

- Sessions are deleted after 24 hours.
- The host link is private. Only its holder controls the session.
- All traffic is encrypted (HTTPS).
- Everything viewers send is cleaned before it is shown.
- Per-network limits stop spam and abuse.
